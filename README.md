# Push Arena

판 위에서 서로 밀쳐 떨어뜨리는 웹 멀티플레이 게임.

## 실행
```
npm install
npm start
```
브라우저에서 http://localhost:3000 접속.
- 방 만들기: 4자리 방 코드가 생기고 만든 사람이 방장(👑). 친구는 코드를 입력해 입장
- 빠른 시작: 빠른 시작을 누른 사람끼리 한 방에 모임
- 방장만 시작, 빈자리 AI 켬/끔(기본 끔), 다른 사람 내보내기 가능. 방장이 나가면 다음 사람이 방장
- 게임이 시작된 방에는 아무도 못 들어옴. 게임 중 🚪 버튼으로 나갈 수 있음
- 게임이 끝나고 "다시 하기"를 누르면 바로 새 방으로. 누른 사람끼리 같은 새 방에 모임
혼자 테스트: 표지에서 "봇이랑 연습하기" (봇 3명과 나만의 방)
맵 규칙 하나만 테스트: `MAP_RULE=collapse npm start` (collapse 바닥 붕괴 / tilt 기울기 / ice 빙판길 / shrink 축소 / rain 구멍 비 / lowgrav 저중력 / spin 회전판 / big 거대화 / bounce 튀는 바닥)
카드 테스트: `TEST_CARDS=quake,banana npm start` (게임 시작할 때 모두에게 그 카드를 줌)

## 구조
- `server/config.js` — 모든 게임 수치
- `server/arena.js` — 육각형 타일 맵 (타일별 alive 상태, 발밑 판정)
- `server/abilities.js` — 능력 카드 47장 (스탯/스킬/규칙/트레이드오프, 등급 확률 일반 64·희귀 32·전설 3·신화 1, 1등보다 뒤질수록 희귀·전설 확률 ↑(신화는 고정 1%), 스탯·트레이드 카드는 같은 걸 최대 2장)
- `server/skills.js` — 스킬 22종 (거인 변신, 시간 정지, 운석, 불사조 포함. 돌진, 방어막, 충격파, 순간교체, 내려찍기, 블랙홀 구슬, 바나나 껍질, 거울 세계, 자석 손, 유령, 지진, 지뢰, 점프, 타일 복구, 텔레포트, 얼음 지대, 볼링, 분신)
- `server/bot.js` — 연습용 봇 AI (상대 추적, 낙하 지점 회피, 밀치기)
- `server/room.js` — 방 1개의 게임 로직 (이동, 밀치기, 체력/기절, 라운드)
- `server/index.js` — HTTP + WebSocket, 방 관리 (방 코드, 빠른 시작, 다시 하기 → 새 방)
- `public/client.js` — Three.js 씬, 맵/효과, 네트워크, 입력
- `public/js/character.js` — 캐릭터 모델(후드티 캐릭터), 표정, 모션(대기/이동/밀치기/맞기/기절/낙하)
- `public/js/ui.js` — 표지, 능력 카드, HUD, 이름표
- `public/js/podium.js` — 최종 순위 시상대 (1·2·3등 단, 꽃가루)
