# Push Arena

판 위에서 서로 밀쳐 떨어뜨리는 웹 멀티플레이 게임.

## 실행
```
npm install
npm start
```
브라우저에서 http://localhost:3000 접속.
- 방 만들기: 4자리 방 코드가 생기고 만든 사람이 방장(👑). 친구는 코드를 입력해 입장
- 빠른 시작: 빠른 시작을 누른 사람끼리 한 방에 모임
- 방장만 시작, 빈자리 AI 켬/끔(기본 끔), 다른 사람 내보내기 가능. 방장이 나가면 다음 사람이 방장
- 게임이 시작된 방에는 아무도 못 들어옴. 게임 중 🚪 버튼으로 나갈 수 있음
- 게임이 끝나고 "다시 하기"를 누르면 바로 새 방으로. 누른 사람끼리 같은 새 방에 모임
혼자 하기: 표지에서 "봇이랑 연습하기" (봇 3명과 나만의 방, 옆에서 난이도 쉬움 / 보통 / 어려움)
조작: 키보드(WASD · Space · Q/E · 마우스) · 폰 터치 · 게임패드(왼쪽 스틱 이동, A/RT 밀치기, LB/RB 스킬, 오른쪽 스틱 시점, 십자키 감정. 카드·대기실·순위 화면은 좌우로 고르고 A)
맵 규칙 하나만 테스트: `MAP_RULE=collapse npm start` (collapse 바닥 붕괴 / tilt 기울기 / ice 빙판길 / shrink 축소 / rain 구멍 비 / lowgrav 저중력 / spin 회전판 / big 거대화 / bounce 튀는 바닥)
카드 테스트: `TEST_CARDS=quake,banana npm start` (게임 시작할 때 모두에게 그 카드를 줌)
맵 모양 하나만 테스트: `MAP_SHAPE=donut npm start` (full 육각형 / donut 가운데가 뚫림 / bridge 다리 하나로 이어진 두 섬)
짧은 게임: `WIN_SCORE=2 npm start` (2점 먼저 따면 우승)

## 테스트
```
npm test
```
- `tools/simtest.mjs` — 실제 시간 없이 방을 끝까지 돌려 봄: 맵 규칙 9종 × 봇 난이도 3단계, 스킬 전부, 난이도별 승률 → `ALL OK`
- `tools/progresstest.mjs` — 성장 계산(경험치 · 해금 · 도전 과제 · 일일 미션 · 저장) → `ALL OK`
- 브라우저 콘솔의 `window.__game` (state · myId · views · press): localhost 또는 주소에 `?debug`가 있을 때만 열림

## 게임 흐름
- 능력 카드 1장 고르기 → 카운트다운 → 라운드(마지막까지 남은 사람이 1점) → … → 5점 먼저 따면 우승
- **맵 모양**: 라운드마다 맵 규칙과 따로 뽑음 (육각형 5 : 도넛 2 : 다리 2, `MAP_SHAPES`). 빠진 타일은 처음부터 뚫려 있고 복구되지 않음. 시작 자리는 가장 가까운 타일로 맞춤
- **서든데스**: 라운드가 35초를 넘기면 맵 규칙과 상관없이 바깥 겹부터 4초마다 영구히 무너지고(타일 복구로도 못 고침) 한 겹마다 밀치기 +12% → 라운드는 길어도 70초 안에 끝남
- **KO**: 떨어지기 3초 안에 민 사람의 처치. 4초 안에 연달아 떨어뜨리면 더블 · 트리플 KO. 마지막 상대가 떨어지는 순간 0.9초 슬로모션
- **시상**: 게임이 끝나면 한 사람에게 상 하나씩 (철거반장 · 한 방에 여럿 · 매운 손 · 끈질긴 생명력 · 단골 낙하산 · 참가상)
- **성장** (브라우저에 저장, 계정 없음): 게임을 끝까지 하면 경험치 → 레벨 40까지. 레벨과 도전 과제로 모자 19종 · 칭호 23종이 열림. 도전 과제 22개, 날마다 바뀌는 일일 미션 3개, 고른 카드가 모이는 카드 도감. 봇 연습은 경험치를 덜 받음 (쉬움 ×0.5 / 보통 ×0.7 / 어려움 ×0.9)

## 구조
- `server/config.js` — 모든 게임 수치
- `server/arena.js` — 육각형 타일 맵 (타일별 alive 상태, 발밑 판정, 맵 모양 `SHAPES`)
- `server/abilities.js` — 능력 카드 47장 (스탯/스킬/규칙/트레이드오프, 등급 확률 일반 64·희귀 32·전설 3·신화 1, 1등보다 뒤질수록 희귀·전설 확률 ↑(신화는 고정 1%), 스탯·트레이드 카드는 같은 걸 최대 2장)
- `server/skills.js` — 스킬 22종 (거인 변신, 시간 정지, 운석, 불사조 포함. 돌진, 방어막, 충격파, 순간교체, 내려찍기, 블랙홀 구슬, 바나나 껍질, 거울 세계, 자석 손, 유령, 지진, 지뢰, 점프, 타일 복구, 텔레포트, 얼음 지대, 볼링, 분신)
- `server/bot.js` — 봇 AI (상대 추적, 낙하 지점 회피, 밀치기). 난이도 표 `LEVELS`: 생각 속도 · 밀칠 확률 · 스킬 · 돌아 들어가기
- `server/room.js` — 방 1개의 게임 로직 (이동, 밀치기, 체력/기절, 라운드, 서든데스, KO 기록 `onFall`, 시상 `AWARDS` · `ranking`)
- `server/index.js` — HTTP + WebSocket, 방 관리 (방 코드, 빠른 시작, 다시 하기 → 새 방), `/api/catalog`(카드 목록)
- `public/client.js` — Three.js 씬, 맵/효과, 네트워크, 입력, 카메라(반동 · 슬로모션)
- `public/js/character.js` — 캐릭터 모델(후드티 캐릭터), 모자 `HATS`, 표정, 모션(대기/이동/밀치기/맞기/기절/낙하)
- `public/js/fx.js` — 입자 효과 (파편 · 먼지 · 타일 조각 · 꽃가루 · 바람 줄기). InstancedMesh 두 개
- `public/js/ui.js` — 표지, 능력 카드, HUD, 이름표, 킬 피드 · 큰 알림, 게임패드로 고르기
- `public/js/progress.js` — 성장 계산만 (레벨, 칭호 `TITLES`, 모자 해금 `HAT_UNLOCK`, 도전 과제 `ACHIEVEMENTS`, 일일 미션 `MISSIONS`, `applyMatch`)
- `public/js/meta.js` — 성장 화면 (레벨 막대, 미션 · 도전 과제 · 도감 · 내 기록 창, 게임 끝 보상)
- `public/js/gamepad.js` — 게임패드 읽기
- `public/js/podium.js` — 최종 순위 시상대 (1·2·3등 단, 꽃가루)

개수를 맞춰야 하는 것: 모자 = `HATS`(character.js) = `HAT_UNLOCK`(progress.js) = `HAT_COUNT`(config.js) / 칭호 = `TITLES`(progress.js) = `TITLE_COUNT`(config.js). `npm test`가 확인함
